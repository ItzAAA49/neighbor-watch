# NEIGHBOR WATCH — 1955年の入居審査室

監査ビルド v1.6.1

日本語・オリジナル作画による、提示された『That's Not My Neighbor』仕様書をベースにしたファンメイドのブラウザゲームです。Steam 2.0相当の5日間キャンペーンを基本に、チュートリアル、アーケード、ナイトメア、カスタム、カードゲームを実装する構成です。

## 起動

```bash
npm install
npm start
```

`http://localhost:3000` で開きます。

## Renderで公開する

1. GitHubで新しい空の公開リポジトリを作成し、このフォルダーの中身を `main` ブランチへ push します。既存の別ゲーム用リポジトリへ上書きしないでください。
2. Renderで **New → Blueprint** を選び、そのGitHubリポジトリを接続します。ルートの `render.yaml` を読み込んで作成します。
3. アカウント／ゲストのサーバー保存を永続化するには、Render PostgreSQLを作成し、Webサービスの `DATABASE_URL` にInternal Database URLを設定します。
4. デプロイ後、`/health` が `database: connected` を返すことを確認します。

PostgreSQLを設定しない場合もローカルのゲスト保存・アカウント機能は動きますが、Render Freeの一時ファイルシステムではサーバーファイル保存が再起動・再デプロイ後に残る保証はありません。ブラウザ保存も併用します。

## 著作権・表現

本作は非公式ファンメイド作品です。原作の画像・音声・本文は使用せず、UI、顔イラスト、書類、短い効果音は独自生成しています。原作の権利者とは無関係です。ホラー表現は雰囲気中心で、露骨な流血・負傷描写は避けています。

## 検証状況

`npm test` は次の順に実行します。

- JavaScript構文検査（server / data / face / common / game）
- ゲームのスモークテスト（40人分の名簿・顔、全ページの参照、キャンペーン・チュートリアル・カスタム・ナイトメア・アーケード・カード、複数シードの連続勤務）
- セーブ・画面遷移テスト（非同期復元、ページ離脱時保存、端末間マージ、二重開始防止、キャンペーン日送りの冪等性）
- HTTPサーバー統合テスト（ヘルス、全ページ、ログイン、認証、ゲスト／アカウント保存、入力上限、破損セーブの退避）

ゲームロジックのテストは軽量なDOMテスト環境で実際のイベントハンドラーを動かします。サーバー統合テストはHTTPリクエストを実際のExpressサーバーへ送ります。テストに通ることは既知の再現ケースを減らすためのもので、全ブラウザ・全端末で不具合がゼロである保証ではありません。Chromebook向けにCanvasや重い3Dエンジンを使わず、SVGとCSS中心で描画しています。

## 実装範囲と既知の省略

この納品物は、ブラウザで遊べる初期完成ビルドです。仕様書の全要素を完全に移植した最終版とは区別してください。現状の主な省略・簡略化は次のとおりです。

- マスクゴーストの「3回入室」イベント、悪チェスターの専用クイズ、6666番電話からの追加エンディングは未実装です。
- カスタムモードは1人の追加住人を作成する簡易編集です。顔パーツを自由に組み替えるキャスト全体の編集画面ではありません。
- 32種類の指名手配対象は収集データとして用意していますが、本家と同じ専用ポスター絵を32枚個別に描いたものではありません。
- 一部の来訪者の固有会話、電話の例外応答、全てのドッペルゲンガー専用変異・質問分岐は簡略化しています。
- 本家の全演出・全アニメーション・全エンディング分岐の細部までは再現していません。2.1.0専用要素は追加仕様として一部のみです。

## 保存・アカウントについて

アカウントのパスワードはbcryptでハッシュ化します。PostgreSQL接続時はアカウントとゲストのセーブをDBへ保存します。ログインセッションはサーバーメモリ上のトークンなので、サーバー再起動後は再ログインが必要です。セーブ本体はDBに残ります。


## v1.6.0 — 本家2.1.0の公開設計から取り入れた機能

- 住人20人それぞれに性格・話し方・質問への返答を追加。ドッペルゲンガーは別人の話し方を装う場合があります
- 住人名簿に住人別の個人メモ（最大500文字）を追加。ローカル保存とセーブ同期に対応
- キャンペーン・アーケードで、未収集ポスターを優先するポスター対象を各勤務に1人保証
- 通常勤務ではチェック表を任意入力に変更。チュートリアルでは4項目すべての入力を必須にして学習フローを維持
- 電話3312から部屋を選び、ドッペルゲンガーを誤入室させた部屋の清掃依頼が可能。未処理の部屋が残れば勤務失敗
- 緊急回線を使った旧通報手順も互換性のため残しつつ、D.D.D.通報ボタンから直接確認へ進める
- キャンペーンの勤務結果から、その日が成功・失敗のどちらでも開始前の状態に戻して再挑戦可能
- エンディングを7種類に拡張（条件と文章はNEIGHBOR WATCH独自の内容）

本家の公開更新情報にない細部は完全一致とはせず、ファンゲーム独自の解釈として実装しています。本家の画像・音声・台詞を複製せず、既存の独自SVG/CSSと新規文章を使用しています。Renderのサーバー側セーブ永続化にはPostgreSQLのDATABASE_URLが必要です。
